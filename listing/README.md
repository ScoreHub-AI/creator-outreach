# ScoreHub AI TikTok达人营销专家 · Tiky

Tiky 是 ScoreHub AI 面向 TikTok Shop 卖家打造的达人营销专家。她按类目、GMV、销量、粉丝量级与年龄/性别、内容表现和合作特征发现合适的达人，结合近 30 天带货、内容、品类和受众数据建立清晰可比较的达人画像，并通过精选后的小范围建联快速验证合作假设。Tiky 不是面向成千上万达人的海量群发工具。

## 核心能力

| 能力 | 说明 |
|---|---|
| 达人搜索 | 按类目、用户名或昵称、GMV、销量、粉丝量级、粉丝年龄与性别、内容表现和合作特征筛选；单轮最多返回 60 位并支持继续翻页 |
| 达人画像 | 拉取达人的近 30 天带货、内容与粉丝数据，输出可比较的画像以及 Rank 分数和排名 |
| 建联验证 | 对精选候选人创建会话并发送文本、商品卡片、定向合作邀请、免费样品邀请和图片消息 |
| 相似达人 | 以某位达人为模板，经多路召回与候选粗排返回 Top-N 相似达人（1–50） |
| 店铺数据分析 | 只读复盘已授权店铺的经营总览、联盟贡献、商品表现、商品联盟订单和商品 TOPN 出单达人 |
| 随手查 | 查询当前店铺的样品申请、本人达人回复/聊天和邮件记录；以查询为主，不审批、不寄样、不发信、不建合作 |

## 支持市场

覆盖 19 个国家市场：印度尼西亚（ID）、泰国（TH）、马来西亚（MY）、越南（VN）、菲律宾（PH）、新加坡（SG）、美国（US）、英国（GB）、德国（DE）、意大利（IT）、法国（FR）、西班牙（ES）、爱尔兰（IE）、波兰（PL）、捷克（CZ）、葡萄牙（PT）、日本（JP）、巴西（BR）和墨西哥（MX）。

## 依赖

Tiky 的 TikTok 数据查询与建联操作通过 ScoreHub 提供的 MCP 服务完成。召唤 Tiky 时若该服务尚未连接，WorkBuddy 会引导完成连接；首次调用工具时会打开浏览器登录 ScoreHub 并授权店铺。TikTok API 凭证由 ScoreHub 托管，使用者无需自行配置，也无需编辑任何本地配置文件。

## 典型用法

- 帮我找 20 位印尼美妆达人，粉丝 1 万–10 万，18–34 岁女性粉丝占比至少 60%，GMV 1K+
- 分析一下这几位达人的带货表现，帮我打分排名
- 从排名前 5 位中选出最匹配的 3 位，用现金 + 高佣 Offer 发起建联验证
- 分析我店铺上个月的联盟经营和商品表现
- 看看现在有哪些待审核的样品申请
- 看看最近有哪些达人回复，打开这条回复继续聊
- 查一下我最近的邮件和主动发信统计

## 使用边界

- 搜索与表现查询共享每日 10,000 次调用配额。
- 建联要求店铺 GMV 达标，且店铺与达人处于同一区域。
- 单店铺对单达人存在 IM 消息条数上限。
- 数据分析只读取已授权且完成同步的店铺数据；不自动同步数据、修改业务数据或触发建联。
- 随手查不审批/拒绝样品申请、不寄样、不发信/回复、不建合作、不导出或写同步；明确刷新、打开通知/收件、聊天补存和成员维护等附带行为按对应 Skill 说明。
- Tiky 只做达人搜索、画像评估、店铺数据分析、精选建联验证与已有记录查询，不提供面向成千上万位达人的群发能力。
