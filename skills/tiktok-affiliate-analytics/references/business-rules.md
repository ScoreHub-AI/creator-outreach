# 联盟经营分析业务规则 Reference

本文件承载 Skill 运行时的结论强度、数据状态、范围降级和禁止动作。本文件为这些解释规则的 owner；指标与关联细节分别见 [指标定义](./metric-definitions.md) 和 [数据关联](./data-join-and-attribution.md)。

## 结论强度

按以下层级表达结果：数据事实 → 观察性判断 → 风险信号/机会点 → 人工决策建议。样本小、覆盖不足或关键字段缺失时，只输出事实或使用“可能”“值得关注”等弱结论。

不得把相关性表达为因果关系，不得把单个指标或单个对象结果变成未经确认的全局阈值。

风险或机会原则上至少需要两个相互支持的事实，或一个明确规则结果加一个业务上下文；“集中”“较高”“较弱”等表述优先采用同店、同期或同商品集合的相对比较。规则型预警可以作为风险信号，但不得据此推断具体原因。

## 数据状态

| 状态 | 含义 | 处理 |
|---|---|---|
| `complete` | 关键字段和关联完整 | 正常输出 |
| `partial` | 存在未关联、未映射或金额缺失 | 输出可用事实并说明影响范围 |
| `no_data` | 范围内没有可用记录 | 说明暂无数据，不等同于 0 |
| `not_comparable` | 缺少可比周期、分母为 0 或口径不一致 | 说明具体原因，不填零替代 |
| `unavailable` | 本次接口、服务或必要字段不可用 | 保留其他成功结果并说明原因 |

“能力尚未实现”或“超出产品范围”不是 `unavailable`，按范围外策略单独说明。`no_data` 不等同于 0；只有真实查询结果明确为数值 0 时才可写成 0。

覆盖率不设置统一硬性通过阈值，应结合指标重要性、样本量和缺失范围调整结论强度。多种状态同时出现时，优先说明对核心结论影响最大的状态，其余限制集中放在数据限制部分；状态不得静默忽略。状态说明应尽量靠近受影响的事实或结论，也不得以默认零值掩盖。

日期解析遵循 [SKILL.md](../SKILL.md)，不在本文件重复定义。

## 未实现和超出范围

对于商品—内容—订单效果、履约结果弱点、售后与订单质量、独立订单/内容分析或其他超出范围的请求，按“当前结论 → 原因 → 可提供内容 → 限制说明 → 下一步选择”回复。已规划但尚未实现时说明专题状态和当前替代事实；已有数据但关联不足时可以输出部分事实并标注覆盖范围；完全超出能力时明确不支持；不得用口径不同的相近指标冒充目标指标。

当前没有可靠数据支持时，不提供利润率、ROI、库存、广告成本、建联成功率或完整样品申请—履约—出单转化漏斗；也不得声称完整视频出单率或完整达人 GMV 归因。

## 禁止动作

- 不执行数据库写入、DDL 或同步任务启动；
- 不自动建联、发消息、审核样品或修改业务规则；
- 不把商品日报联盟 GMV 当作达人明细金额；
- 不把官方达人整体市场画像当作本店订单结果；
- 不把部分归因包装为全量结果；
- 不虚构数据、概率、原因或 ROI/利润结论。
